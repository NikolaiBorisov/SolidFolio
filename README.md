# 🚀 SolidFolio

A clean, modern portfolio template built with HTML, CSS, and JavaScript.  
Easy to customize, fully responsive, and ready to deploy.

---

## ✨ Features

- 🎯 Minimal & modern design
- 👤 Hero section (avatar, role, availability)
- 🧠 About Me section
- 🌟 Soft & Hard Skills
- 🛠️ Tools section
- 💼 Experience & Projects
- 📮 Contact & Social links
- 🌐 Multi-language support (EN / ES, extendable)
- ⚡ Smooth animations
- 📱 Fully responsive (mobile-friendly)
- 🚫 No frameworks (pure HTML, CSS, JS)

---

## 🚀 Getting Started
Clone the repository

```bash
git clone https://github.com/your-username/SolidFolio.git
```

## ⚙️ Customization
Edit content in index.html
Update translations in js/script.js
Replace avatar in /img
Add your projects & links

## 🧩 Tech Stack
HTML5
CSS3 (Flexbox, Grid, Animations)
Vanilla JavaScript

## 💡 Usage

Copy → Paste → Adjust → Use
